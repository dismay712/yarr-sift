主界面分为三个区域。

1. **Feed 列表** - 用于选择 Feed 或文件夹。
2. **文章列表** - 显示当前选择项中的文章。
3. **文章内容** - 显示所选文章的具体内容。

每个区域顶部都有一个带有相应操作按钮的顶栏。

**Feed 列表** 的顶栏包含：

- 过滤器 - 按未读、加星标记或所有文章进行筛选
- 全局设置菜单 - 添加或刷新 Feed、切换主题、设置自动刷新频率、选择排序方式、导入/导出订阅、查看快捷键以及切换语言

**文章列表** 的顶栏包含：

- 搜索框 - 在当前选择范围内搜索
- 全部标记为已读 - 将当前选择范围内的所有文章标记为已读（仅在选择“未读”过滤器时可见）
- 所选 Feed 或文件夹的设置菜单 - 打开网站、重命名、移动或删除

**文章内容** 的顶栏包含针对所选文章的操作：

- 加星切换 - 将文章标记为加星
- 已读切换 - 将文章标记为已读或未读
- 文章外观设置 - 选择字体并调整文本大小
- 在此阅读 - 获取并显示完整的文章内容
- 在浏览器中打开 - 在新标签页中打开文章链接
- 左箭头 - 导航至列表中的上一篇文章
- 右箭头 - 导航至列表中的下一篇文章
- 关闭 - 关闭并取消选择当前文章

## 定时提取原文

1. 选中一个订阅，打开文章列表顶栏的「⋯」，选择「提取原文」。
2. 在「正文选择器」中填写匹配目标区域的 CSS 选择器。例如，若正文在 `<div class="entry-content">` 中，填写 `.entry-content`。如果还想去掉正文里的广告与相关推荐，在「排除选择器」中填写 `.ad, .related`。选择器应与原网页的 HTML 对应。
3. 保存规则，在订阅列表的设置菜单中点击「刷新订阅」即可试用。要定时运行，在同一菜单的「自动刷新」中选择间隔，例如 `30m`，并保持 Yarr Sift 运行。

每轮刷新会分批处理新条目和已保存的旧条目。提取器直接访问公开的 HTTP(S) 网页，读取服务器返回的 HTML，保留选中区域的文字与换行。需要登录或由 JavaScript 加载的正文可能无法提取。抓取失败或没有匹配到文本时，阅读器会显示原订阅内容，并在后续刷新时重试。

同一规则成功处理过的条目会跳过。修改规则后，已有条目会按新规则重新提取。清空正文选择器并保存即可停用，并恢复该订阅原有的内容。
